# Основные понятия

**Zephyr** - операционная система, которая основана на ядре с небольшим объемом памяти, разработанном для использования в системах с ограниченными ресурсами и встроенных системах: от простых встроенных датчиков окружающей среды и светодиодных носимых устройств до сложных встроенных контроллеров, умных часов и беспроводных приложений IoT.

**West** - универсальный инструмент командной строки, входящий в проект Zephyr. West разрабатывается в собственном репозитории.

Встроенные команды West предоставляют систему управления несколькими репозиториями с функциями, вдохновленными инструментом Google Repo и подмодулями Git. West также является «подключаемым»: вы можете писать собственные команды расширения West, которые добавляют дополнительные функции. Zephyr использует это для обеспечения удобства при сборке приложений, их прошивке и отладке, и многом другом.

**Zephyr (SDK)** - комплект разработки программного обеспечения, который содержит наборы инструментов для каждой из поддерживаемых Zephyr архитектур. Он также включает дополнительные инструменты для хост-системы, такие как пользовательские QEMU и OpenOCD.

Пакет Zephyr SDK поддерживает все основные операционные системы (Linux, macOS и Windows) и поставляется в виде сжатого файла. Установка заключается в распаковке файла и запуске прилагаемого скрипта установки.
