# Демонстрация генерации 16 байт

### 1. Описание теста

Для быстрой демонстрации работы FAPI GetRandom был создан минималистичный тест.

**Файл:** [`sw/device/tests/fapi_getrandom_demo.c`](source/fapi_getrandom_demo.c)

Этот тест демонстрирует базовую функциональность:
1. Инициализация CSRNG
2. Генерация ровно 16 случайных байт
3. Вывод данных в hex и decimal формате

### 2. Запуск теста

```bash
cd /root/opentitan
./bazelisk.sh test //sw/device/tests:fapi_getrandom_demo_sim_verilator \
  --test_output=streamed
```

### 4. Анализ сгенерированных данных

Hex данные:

```
1e ca 8f 37 08 3d 76 cf 90 6e 16 17 08 53 16 0b
```

Decimal данные:

```
30 202 143 55 8 61 118 207 144 110 22 23 8 83 22 11
```

Анализ полученных результатов:
- Все 16 байт содержат ненулевые значения
- Значения от 8 до 207, охватывают большую часть возможного диапазона 0-255
- Нет очевидных последовательностей или повторений
- Визуально данные выглядят случайными

Эта демонстрация показывает, что FAPI GetRandom успешно генерирует криптографически стойкие случайные числа с использованием аппаратного CSRNG модуля OpenTitan.
