# Дополнительная верификация: CSRNG unit-тест

Для более глубокой проверки качества CSRNG был создан дополнительный тест:

**Файл:** [`sw/device/tests/fapi_csrng_unit_test.c`](source/fapi_csrng_unit_test.c)

Этот тест проверяет непосредственно CSRNG модуль без протокольного уровня:

```c
static status_t test_various_sizes(void) {
  const size_t test_sizes[] = {16, 32, 64, 128, 256};

  for (each size) {
    csrng_get_random(buffer, size);
    // Проверка что данные не нулевые
    // Вывод данных для визуальной проверки
  }
}

static status_t test_statistics(void) {
  uint8_t buffer[256];
  csrng_get_random(buffer, 256);

  // Подсчет битовой статистики
  uint32_t bit_count = 0;
  for (each byte) {
    for (each bit) {
      if (bit is set) bit_count++;
    }
  }

  // Проверка распределения (ожидается ~50% единиц)
  // Допустимый диапазон: 900-1148 из 2048 бит (44%-56%)
  TRY_CHECK(bit_count >= 900 && bit_count <= 1148);
}
```
