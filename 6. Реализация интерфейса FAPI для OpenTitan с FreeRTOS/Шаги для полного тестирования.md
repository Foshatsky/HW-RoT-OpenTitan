# Шаги для полного тестирования

Для демонстрации полного тестового фреймворка минимального интерфейса FAPI GetRandom необходимо проделать шаги, описанные ниже.

### 1. Переход в директорию OpenTitan

```bash
cd /root/opentitan
```

###  2. Сборка тестового фреймворка

```bash
./bazelisk.sh build //sw/device/tests:fapi_getrandom_server_test_sim_verilator
```

Результат завершения сборки должен быть следующим:

```
INFO: Build completed successfully
Target //sw/device/tests:fapi_getrandom_server_test_sim_verilator up-to-date
```

### 3. Запуск тестов интерфейса

```bash
./bazelisk.sh test //sw/device/tests:fapi_getrandom_server_test_sim_verilator \
  --test_output=streamed
```

В процессе выполнения тестов можем наблюдать:

```
I00013] === Test 1: Valid request processing ===
I00014] Test 1.1: Request 16 bytes
I00015] Generated 16 random bytes
I00016] Test 1.1: PASSED - received 16 non-zero bytes
```

По завершении видим:

```
//sw/device/tests:fapi_getrandom_server_test_sim_verilator    PASSED in 208.3s
Executed 1 out of 1 test: 1 test passes.
```
