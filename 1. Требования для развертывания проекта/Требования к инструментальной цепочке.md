# Требования к инструментальной цепочке

Для сборки программного обеспечения OpenTitan необходима кросс-компиляция под архитектуру RISC-V 32-bit. Проект использует инструментальную цепочку, основанную на LLVM (clang), предоставляемую в репозитории lowrisc-toolchains. Внутри системы сборки Bazel она сконфигурирована как целевой toolchain, поэтому разработчикам не требуется вручную устанавливать компилятор – Bazel автоматически подтянет нужную версию. Тем не менее, важны следующие требования к инструментам:

- **Компилятор и линкер RISC-V** – должны поддерживать целевую архитектуру RV32IMC с расширениями B (bit-manipulation), т. к. Ibex в OpenTitan использует этот набор команд. Обычно применяется стандартный GNU toolchain (riscv32-unknown-elf-gcc, binutils) или эквивалентный clang/LLVM кросс-компилятор. Компилятор должен уметь генерировать исполняемые образы под bare-metal (т. е. с libc/newlib, без OS). В комплект toolchain входят утилиты вроде objdump, objcopy и др. для RISC-V ELF-файлов.
- **Система сборки Bazel** – OpenTitan целиком собирается с помощью Bazel; в репозитории предоставлен скрипт bazelisk.sh для установки нужной версии Bazel и удобного запуска команд сборки. Таким образом, наличие Bazel (версия ~6.x) является необходимым требованием для сборки проекта.
- **Средства симуляции и верификации** – Для запуска аппаратной модели OpenTitan в софтварной среде требуется Verilator (open-source SystemVerilog симулятор). Версия Verilator рекомендуется установить заранее; пошаговое руководство по установке дано в документации. Verilator используется для быстрой итеративной проверки RTL, и он интегрирован в CI (напр., код не будет слит без прохождения Verilator lint). Если есть доступ к проприетарным симуляторам (Cadence Xcelium, Synopsys VCS), они тоже поддерживаются, но для open-source contributors Verilator – основной инструмент.
- **Инструменты FPGA (опционально)** – Если планируется синтезировать дизайн OpenTitan на FPGA, необходимы утилиты от производителя FPGA. В частности, для поддерживаемых Xilinx FPGA используется Xilinx Vivado. Для некоторых задач достаточно бесплатной Vivado Lab Edition (например, "сплайсинг" обновленного ПЗУ в готовый битстрим), однако для полного синтеза битстрима потребуется полная версия Vivado с соответствующей лицензией. FuseSoC/Bazel автоматически запускает Vivado в процессе сборки битстрима.
- **Прочие зависимости** – Стандартные утилиты сборки (Make, coreutils), Python 3 с рядом библиотек (указаны в python-requirements.txt), Git, а также инструменты для работы с устройством (например, драйверы кабелей JTAG/UART, если планируется отладка на железе). Документация рекомендует установку требуемых пакетов через список apt-requirements.txt на Ubuntu, куда входят компиляторы, build-essential, device-tree-compiler, libusb, cmake, etc. (все необходимое для сборки и запуска инфраструктуры OpenTitan).

**Как промежуточный итог:** разработчику OpenTitan нужен RISC-V кросс-компилятор + Bazel, среда Linux с установленными зависимостями, симулятор Verilator для RTL, и при необходимости – Vivado для работы с FPGA. Эти инструменты обеспечивают полный цикл: от компиляции прошивок и генерации образов до моделирования и отладки SoC.
