# Структура базового проекта OpenTitan

OpenTitan хранится в виде монолитного репозитория (monorepo), содержащего все компоненты – RTL-дизайн, программное обеспечение, утилиты и документацию – в едином дереве исходников. В корне репозитория находятся основные директории:

 - **hw/** – аппаратная часть (RTL модули и средства верификации). Здесь расположены поддиректории IP-блоков и чипа: например, hw/ip (отдельные ядра периферии с их RTL-кодом, документацией, тестбенчами на SV/UVM и др.), hw/top_earlgrey (top-level SoC дизайн Earlgrey, включающий интеграцию всех IP), а также общие ресурсы hw/dv (библиотеки для тестбенчей), hw/formal (формальная верификация), hw/lint (скрипты статического анализа) и пр.
- **sw/** – программное обеспечение проекта. Внутри него: sw/device – код, выполняющийся на встроенном процессоре OpenTitan. Он включает поддиректории с примерами (examples/, например hello_world для демонстрации базовой работы), бенчмарками (например, CoreMark), специфичными для разных целей расширениями (exts/ для FPGA, симуляции и др.), а также библиотеками и драйверами (DIF – Device Interface Functions) и тестовым фреймворком OTTF. Тестовые программы для устройства собираются в sw/device/tests. Помимо этого, sw/host содержит утилиты, выполняющиеся на компьютере-хосте и взаимодействующие с OpenTitan (например, прошивка, отладочные инструменты), а sw/vendor – подключенные сторонние библиотеки (например, криптографические).
 - **doc/** – подробная документация по архитектуре, IP-блокам, руководства для пользователей и разработчиков.
-  **util/** – скрипты и утилиты для обслуживания проекта (генераторы кода, сборочные скрипты и пр.).

Таким образом, структура проекта организована логично по слоям: hw для железа, sw для софта, плюс вспомогательные каталоги doc и util. Это облегчает навигацию и совместную разработку различных компонентов OpenTitan.
