# Технические требования

### 1. Язык разработки

Основная аппаратная часть OpenTitan разработана на языке SystemVerilog (RTL), с ограничением по стилю согласно рекомендациям lowRISC. Программное обеспечение для встроенного RISC-V процессора пишется преимущественно на языке C (с вкраплениями ассемблера и возможностью использования Rust для встроенного кода). Также широко используются скрипты на Python (например, для генерации кода, сборки и верификации). Статистика репозитория подтверждает такой стек: ~47.8% кода написано на SystemVerilog, 18.7% – на C, 7.7% – на Python, 6.5% – на Rust и т. д.

### 2. Среда выполнения ПО

OpenTitan представляет собой встроенную систему на кристалле, основанную на 32-битном ядре RISC-V Ibex. Все программное обеспечение проекта выполняется непосредственно на этом встроенном процессоре. В SoC OpenTitan (кодовое имя Earl Grey) используется RV32IMCB ядро Ibex (32-разрядный RISC-V с поддержкой умножения, атомарных операций, компактных инструкций (C) и частичного набора битовых расширений B). Это ядро работает в двух режимах (Machine/User) и оснащено расширенными механизмами защиты памяти (ePMP); для повышения надежности оно может работать в режиме двуядерного lockstep, а также содержит аппаратные средства безопасного исполнения (защита по контрольной сумме регистра PC, скремблирование инструкций в кеше и пр.).

ПО OpenTitan (прошивки) работает без операционной системы (bare-metal) – на уровне загрузчика и монолитных приложений. В состав софта входит, например, начальный загрузочный ROM, реализующий secure boot, и набор прикладных программ/тестов для проверки работы устройства. Они выполняются во встроенной памяти чипа (OpenTitan располагает 128 КБ ОЗУ, 32 КБ ПЗУ ROM, ~1 МБ встроенной флеш-памяти, OTP и др.) и взаимодействуют с периферией чипа напрямую через регистровые интерфейсы. Периферийные компоненты SoC включают GPIO, UART, SPI, I2C, таймеры, крипто-модули (AES, HMAC/SHA-256, KMAC/SHA-3), аппаратный генератор случайных чисел, менеджер ключей и прочие контроллеры безопасности.

Таким образом, средой выполнения программ OpenTitan является сам разработанный SoC (реализованный либо на FPGA, либо впоследствии в виде ASIC), где код выполняется на встроенном RISC-V процессоре Ibex без операционной системы (прямой доступ к железу). Для разработки и отладки эта среда может быть воспроизведена в симуляторе (например, Verilator или QEMU) или на прототипе FPGA, имитирующем работу чипа.
