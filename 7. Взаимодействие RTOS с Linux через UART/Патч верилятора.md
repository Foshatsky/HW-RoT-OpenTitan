# Патч для верилятора

### Что за патч?

Данный патч обновляет экран (UART) после каждого введенного символа путем
сброса буферизованных данных в устройство вывода данных. Это позволит
мгновенно наблюдать реакцию RTOS с внешнего окружения (RTOS -> UART -> OS).

Без этого изменения сброс сработает только при выполнении функции
`uartdpi_close`, которая вызывается при закрытии UART.

---

## Применение патча

Для того, чтобы применить патч, необходимо клонировать репозиторий `verilator`
(делалось ранее в [../2. Подготовка рабочего окружения/Настройка программной среды.md](../2.%20Подготовка%20рабочего%20окружения/Настройка%20программной%20среды.md))

После чего открыть файл `uartdpi.c`, находящийся по пути:

```

hv/dv/dpi/uartdpi/uartdpi.c

````

И в функции:

```c
int uartdpi_write(void *ctx_void, char c)
````

заменить блок:

```c
if (ctx->log_file) {
  rv = fwrite(&c, sizeof(char), 1, ctx->log_file);
  assert(rv == 1 && "Write to log file failed.");
}
```

на:

```c
if (ctx->log_file) {
  rv = fwrite(&c, sizeof(char), 1, ctx->log_file);
  assert(rv == 1 && "Write to log file failed.");
  fflush(ctx->log_file);
}
```

таким образом, сразу после того как в файл `ctx->log_file` будет
введен символ, выполнится `fflush`, который сразу же запишет этот символ
в устройство вывода.

---

Остается только выполнить перекомпиляцию веритора с измененными исходниками командой:

```bash
./bazelisk.sh build //hw:verilator
```
