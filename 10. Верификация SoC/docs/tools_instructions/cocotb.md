# cocotb — COroutine based COsimulation TestBench

Установка через pip:
```bash
source venv/bin/activate
pip install cocotb
```

Требует Icarus Verilog или Verilator для HDL-симуляции.

- [Constrained_random_testing](../03_microarchitecture_rtl/03_01_informal/Constrained_random_testing.md)
