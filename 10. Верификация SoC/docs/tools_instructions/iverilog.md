# Icarus Verilog (iverilog)

Установка из системного пакета:
```bash
# Ubuntu/Debian
sudo apt install iverilog

# Проверка версии
iverilog -V
```

Версия 12.0 и выше поддерживает `#delay` для timing simulation.
