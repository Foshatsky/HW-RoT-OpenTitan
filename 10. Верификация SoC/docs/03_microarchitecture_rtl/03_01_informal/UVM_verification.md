### МЕТОД: Универсальная методология верификации (UVM)
### КАТЕГОРИЯ: 3. Микроархитектурная и RTL-верификация / Неформальная
### ФОРМАЛЬНОСТЬ: неформальный

### СУТЬ МЕТОДА:
UVM (Universal Verification Methodology, IEEE 1800.2) – промышленный стандарт для построения структурированных тестовых окружений на SystemVerilog. Это не инструмент, а методология: библиотека классов, архитектурных шаблонов и правил, которые позволяют создавать масштабируемые, повторно используемые тестбенчи.

Как это работает: тестовое окружение строится из иерархии компонентов: Test запускает Env, Env содержит Agent (Driver + Monitor + Sequencer), Agent управляет транзакциями между sequence (генератор тестов) и DUT (тестируемое устройство). Scoreboard сравнивает поведение DUT с эталоном. Фабрика объектов UVM позволяет конфигурировать тестбенч без изменения исходного кода.

Для верификации процессоров RISC-V UVM используется в проектах OpenHW Group (CORE-V CV32E40P, CVA6) для конвейерной верификации, проверки кэша, MMU. Поскольку коммерческие UVM-симуляторы платные, в open-source RISC-V сообществе часто используют cocotb (Python) или Verilator как альтернативу.

### ВЫВОД ПО МЕТОДУ:
UVM — обязательный стандарт для промышленной верификации ASIC/FPGA, обеспечивающий структурированный тестбенч с чётким разделением ответственности и повторное использование компонентов. Альтернатива для open-source: cocotb + Verilator.
