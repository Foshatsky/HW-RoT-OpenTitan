### МЕТОД: Полуформальная верификация (Bounded Model Checking)
### КАТЕГОРИЯ: 3. Микроархитектурная и RTL-верификация / Полуформальная
### ФОРМАЛЬНОСТЬ: полуформальный

### СУТЬ МЕТОДА:
Полуформальная верификация в широком смысле занимает промежуточное положение между имитационным моделированием (simulation) и полной формальной верификацией. Основной представитель — Bounded Model Checking (BMC): формальный анализ свойств схемы, ограниченный фиксированным числом тактов (глубиной k).

В отличие от полной формальной верификации (которая доказывает свойство для всех возможных состояний и трасс), BMC проверяет только трассы длины ≤ k. Если свойство нарушается в пределах k тактов — BMC найдёт контрпример. Если нет — свойство может быть нарушено на большей глубине.

BMC широко применяется в промышленности для «отлова» багов на ранних стадиях: ~80% дефектов RTL-дизайна проявляются в пределах 10-20 тактов. Комбинируя BMC (поиск багов) с индукцией (полное доказательство), получают гибридный полуформальный подход: быстрый поиск ошибок с последующим доказательством корректности для критических свойств.

Кроме того, такой полуформальный подход может быть использован зачастую фактически без переработки тестбенча — например, рассмотренный в разделе FPV пример можно проверить с помощью BMC.
