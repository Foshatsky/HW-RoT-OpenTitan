# Примеры для Zephyr RTOS

Раздел содержит практические работы и готовый пример реализации криптографического UART-сервиса на базе Zephyr RTOS.

## Структура раздела

```
9. Примеры для ZephyrOS/
├── Examples.md                                          # этот файл
├── crypt_uart/                                          # готовый проект: крипто-сервис на Zephyr
│   ├── CMakeLists.txt                                   # сборочный файл (3 строки)
│   ├── prj.conf                                         # Kconfig: PSA Crypto + Entropy
│   └── src/
│       └── main.c                                       # код сервиса (~140 строк)
├── Практическая работа 1. Разработка UART-сервиса эхо-повтора.md
├── Практическая работа 2. Разработка UART-сервиса генерации ключей.md
└── Пример реализации практической работы №2.md           # детальный разбор crypt_uart
```

## Описание файлов

### crypt_uart/ — готовый проект

Минимальный Zephyr-проект, демонстрирующий:
- Инициализацию UART через Device Tree
- Использование PSA Crypto API для генерации ключей AES-256
- Текстовый протокол команд (`GENKEY`, `STATUS`, `EXIT`)
- Форматированный вывод ключей в HEX

**Сборка и запуск:**

```bash
west build -b opentitan_earlgrey samples/crypt_uart --pristine -DCMAKE_EXPORT_COMPILE_COMMANDS=ON
```

После запуска сервис выводит `READY` и ожидает команды через UART.

### Практическая работа №1 — Эхо-сервис

Базовое задание: разработать UART-сервис, который принимает данные и немедленно отправляет их обратно. Проверяет работоспособность всей цепочки «хост → UART → Zephyr → UART → хост».

**Ключевые навыки:**
- Работа с Zephyr Device Tree
- Polling UART API (`uart_poll_in` / `uart_poll_out`)
- Сборка и запуск через `west`

### Практическая работа №2 — Сервис генерации ключей

Продвинутое задание: сервис, генерирующий криптографические ключи AES-256 и возвращающий их по UART в HEX-формате.

**Ключевые навыки:**
- PSA Crypto API (`psa_crypto_init`, `psa_generate_random`)
- Kconfig-конфигурация (`prj.conf`)
- Текстовый протокол с маркерами для парсинга
- Хост-клиент для автоматического взаимодействия

### Пример реализации практической работы №2

Пошаговое руководство с полным кодом, объяснением архитектурных решений и сравнительным анализом с подходом на FreeRTOS + mbedTLS. Основано на проекте `crypt_uart/`.

## Отличия от FreeRTOS-подхода

| Аспект | FreeRTOS + OpenTitan | Zephyr RTOS |
|--------|----------------------|-------------|
| Сборка | Bazel (специфичен для OpenTitan) | CMake + west (стандарт индустрии) |
| Криптография | Ручная интеграция mbedTLS | PSA Crypto — встроен, включается в Kconfig |
| Аппаратная абстракция | OpenTitan DIF (привязан к чипу) | Device Tree (переносимый) |
| Источник энтропии | Заглушки / ручная настройка | Автоматический выбор (QEMU → test, железо → HW RNG) |
| Стандартная библиотека | Bare-metal заглушки | Полная поддержка newlib/picolibc |
| Переносимость | Только OpenTitan | OpenTitan + десятки других платформ через Device Tree |
