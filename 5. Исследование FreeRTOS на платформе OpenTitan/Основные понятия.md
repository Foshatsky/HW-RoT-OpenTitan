# Основные понятия

**FreeRTOS** - операционная система реального времени (RTOS) для встраиваемых систем. Предоставляет планировщик задач, механизмы синхронизации и таймеры, что позволяет строить предсказуемые по времени многозадачные приложения.

**OTTF (OpenTitan Test Framework)** - тестовый фреймворк OpenTitan для написания и запуска встроенных тестов. В варианте с FreeRTOS часть тестов демонстрирует многозадачность/конкурентность поверх OTTF.

**UART‑лог** - текстовый вывод прошивки (эмуляция последовательного порта), по которому удобно контролировать, что тесты действительно стартуют и завершаются успешно.
