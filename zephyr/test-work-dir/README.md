# Рабочая папка (пример)

Эта папка — **пример** вашей рабочей директории внутри трека Zephyr.

## Что сделать

1. **Скопируйте ветку `dev-z` в новую свою ветку** (не работайте напрямую в `dev-z` / `master`):

```bash
git fetch origin
git checkout dev-z
git pull origin dev-z
git checkout -b <ваша-ветка>
```

Пример имени: `ivan-uart-lab`, `dev-z/maria-notes`.

2. **Создайте новую папку** рядом с этой (или вместо неё) — это **ваша рабочая папка**, в которой вы ведёте материалы:

```bash
mkdir -p zephyr/<ваша-папка>
```

Сюда кладите отчёты, исходники, заметки по заданию.

3. **Пушьте при любых изменениях**, которые хотите сохранить на GitHub:

```bash
git add .
git status
git commit -m "Кратко: что сделали"
git push -u origin <ваша-ветка>
```

Дальше после правок достаточно:

```bash
git add .
git commit -m "…"
git push
```

## Важно

- В **`dev-z`** свои коммиты не пушьте — только через свою ветку, потом merge / PR в `dev-z`.
- Пустая папка в git не хранится: нужен хотя бы один файл (этот README или ваши материалы).
